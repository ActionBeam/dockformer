## Installation

### Dependencies Installation

To install the required dependencies, please use the following command:

```bash
conda env create -f requirement.yaml
```

After the environment is created, activate it with:

Bash

```
conda activate pretrain
```

## Data Preparation

The pre-trained model weights and necessary feature files required for reproduction are available for anonymous download via the following link:

- **Download Link**: [Google Drive Folder](https://drive.google.com/drive/folders/1Yv8Zn7aC8yeirEbQwLLfhYJNpxv2v2p9?usp=drive_link)

Please download and extract the files, then place them in the appropriate directory (e.g., `./Output/parameter/best/`).

## Validation

The predicted SDF files generated by Dockformer are saved in the directory `Output\SDF\sdf`.

To generate results on the PDBbind and PoseBuster datasets, you can activate the corresponding functions `test(opt)` and `test_posebuter(opt)` respectively.

Ensure that you modify the model weights path in the code as follows:

Python

```
# Update the path to point to the downloaded file
checkpoint = torch.load(
    os.path.join('path/to/downloaded/best_parameter_docking.pt'), map_location=f"cuda:{device}")
```

### Running the Test Code

To execute the test code, use the following command:

Bash

```
python train.py --path your_work_path --device your_gpu_id
```
